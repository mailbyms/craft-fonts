# Opt-in native-only Simplified Chinese fonts. Same 8-field format as fonts/manifest.txt:
#   family | style | file (relative to the repo root) | scripts (ISO 15924, comma-separated) | licence | licence file | sha256 | source
# Apps read this file separately from fonts/manifest.txt, and native builds only. It is not part
# of craft-fonts' default FONTS table or embed payload and must never be added to a wasm allowlist.
#
# Fork policy: this fork builds PdfCraft's Simplified Chinese fallback from the Noto regional
# subsets (SubsetOTF/SC) instead of LXGW WenKai Lite, so the LXGW row and its face are gone here.
# The subsets stay well under the 16 MiB native cap (8.3 MB / 11.6 MB); both are OFL-1.1, so a
# redistribution must carry their OFL.txt. Rows keep the upstream "Hans" script tag that native
# builds require, plus Latn for the Latin letters the subsets also draw.
